# ⚡ 电耗记账：电动两轮车的「小熊油耗」，还能全自动记录充电

> 给电动摩托车 / 电动自行车装一个能耗账本：每公里多少钱、电池衰减多少、每月花了多少电费，一目了然。支持纯手动，也支持接 Home Assistant + Node-RED 全自动记。

---

## 为什么做这个

买了极核 AE6+ 这类智能电摩后才发现，官方 App 有电量、有里程，就是**没有能耗统计**——想知道「这车实际百公里耗几度电、每公里花多少钱、电池衰减了多少」，得自己算。

于是做了这个纯前端 PWA：**电耗记账**。数据全在本地/自托管，无广告、无上传，断网也能用。

---

## 主要功能

### 📝 手动记账（一次 10 秒）
- 记一次充电：总里程、充前后电量 %、充电量、电价、费用
- 电价 / 充电量 / 费用三选二自动补全；填电量百分比自动估算充电量
- 勾选「充满」自动填 100%

### 📊 自动统计
- **百公里电耗**（度/百公里）与**每公里成本**
- 电耗曲线：三段渐变（低于平均=蓝/优秀，接近=绿/良好，高于=红/耗电）+ 平均虚线 + 时间轴缩放
- 月度支出统计、费用构成环形图、各项费用分类汇总
- **电池健康估算**：根据每次充电反推当前容量与 SOH，显示年均衰减

### 🚗 多车辆
- 添加 / 切换 / 重命名多辆车，记录、统计、设置完全独立

### 💰 费用与预算
- 保养、保险、停车等支出分类记账
- 月度预算，超支提醒
- 一键导出**本月报告**（次数 / 度数 / 费用 / 里程 / 电耗）

### 💾 数据与备份
- 导入小熊油耗 CSV（老数据直接搬过来）、通用 CSV、JSON
- 每日自动备份（本地 15 份快照 + 可选推送到 NAS）
- 每条快照可单独导出 / 恢复

## 🤖 全自动记录（Home Assistant + Node-RED，可选）

如果你的车有 HA 接入（电量、里程），配一个带计量的智能插座，就能**全自动记录每一次充电**：

1. **换电检测**：车上电量从 <90% 跳到 ≥90% → 判定换了新电池，自动记下「充电前电量 + 里程」
2. **充电会话**：插座功率 >8W 开始，<8W 持续 2 分钟结束；用累计电量表差值算度数（更准，Node-RED 重启也不丢）
3. **异常识别**：一次充电 <0.5 度 → 判定插座用于其他设备，自动忽略
4. **充后电量回填**：装回电池时用实际电量更新记录，不再固定 100%
5. **通知**：换电 / 开始充电 / 充电完成 / 疑似他用都会推送 HA 通知
6. **安全**：接口带访问令牌，只读不公开

> 没配 Node-RED 也不影响使用：手动记账、统计、图表、备份全部照常。

## 应用场合

- 🛵 **日常通勤能耗账本**：每月充电费、每公里成本，心里有数
- 🔋 **双电池轮换**：换电自动识别，两块电池轮着用也不乱
- 📉 **电池健康监测**：容量衰减、SOH 变化曲线，提前发现电池异常
- 💸 **费用预算**：设定月度预算，超支提醒
- 🍂 **季节对比**：冬天电耗高多少，数据说话
