# 电摩能耗自动记账：HA + Node-RED 全自动记录充电，前端 PWA 展示

> 用 Home Assistant 的实体 + Node-RED 自动化 + 一个计量插座，让电摩的每一次充电自动变成能耗账本：百公里电耗、每公里成本、电池衰减（SOH），全自动生成。

---

## 背景

电摩（如极核 AE6+ 这类）官方 App 有电量、里程，但没有能耗统计。HA 里其实已经接了车电量、总里程、插座功率，数据都在，只差把它们变成「有用」的东西。

于是做了两件事：
1. **Node-RED 自动化**：自动识别换电、充电会话，生成一条条充电记录（JSONL 文件）；
2. **前端 PWA「电耗记账」**：展示统计、图表、电池健康，一键同步 Node-RED 的记录。

数据全部自托管，不上云。

---

## 整体架构

```
HA 实体（电量/里程/插座功率/累计电量）
      │
      ▼
Node-RED 自动化（换电检测 / 充电会话 / 生成记录）
      │  ├─ 写 JSONL 记录文件（/data/electric-log/records.jsonl）
      │  ├─ HA 通知（换电/开始充电/完成/异常）
      │  └─ HTTP API（带 token）
      ▼
PWA「电耗记账」── 打开自动同步 → 图表 / 统计 / 电池健康 / 费用
```

## 需要准备

| 数据 | 实体示例（按你自己的替换） |
| --- | --- |
| 车上电量（0-100） | `sensor.battery_level` |
| 总里程 | `sensor.total_odometer` |
| 插座功率（W） | `sensor.charger_power` |
| 插座累计电量（kWh） | `sensor.charger_energy` |

> 最关键的是**带计量功能的智能插座**：既能开关，又能积分出本次充电的度数。

## Node-RED 自动化逻辑

### 1. 换电检测（两电池轮换也能记）

电摩两块电池交替用，车上电量会「跳变」——从 <90% 直接跳到 ≥90%，就是换了新电池。这时：

- 记录**换下来的电池的充电前电量**（跳变前的值）
- 记录**当时的总里程**
- 写入 `pending_swap.json` 挂起（**防 Node-RED 重启丢失**）

### 2. 充电会话检测

- 插座功率 >8W → 开始充电，读取累计电量表起始值
- 功率 <8W 持续 2 分钟 → 确认结束
- 度数 = 结束读数 − 开始读数（比功率积分更准，重启也不丢；异常时自动回退到功率积分）

### 3. 异常过滤

一次充电 <0.5kWh → 判定插座用于其他设备，忽略且保留挂起数据。

### 4. 充后电量回填

装回电池时电量跳变到实际值（比如 96%），自动回填到最近一条记录，不再固定 100%。

### 5. HA 通知

换电、开始充电、充电完成、疑似他用，都推送 `notify.persistent_notification`（可改成手机 App 通知服务）。

### 6. 安全

HTTP API 带访问令牌（`?token=xxx`），403 拦截，可配 NPM 反代 https 外网访问。

## 部署步骤

1. 导入流程：仓库 `node-red/electric-log-flow.json` → Node-RED 菜单 → 导入 → 部署
2. 改实体：4 个 `server-state-changed` / `api-current-state` 节点换成你的实体，选好 HA 服务器
3. Node-RED v4 注意：`settings.js` 的 `functionGlobalContext` 加 `fs: require('fs')`，函数内用 `global.get('fs')`（v4 默认禁用 require）
4. 可选：NPM 反代 `/api/records`、`/api/status`，外网用 https + token 同步

## 前端 PWA「电耗记账」

- **统计**：百公里电耗（度/百公里）、每公里成本、累计度数、本月花费
- **图表**：电耗曲线三段渐变 + 平均虚线 + 时间轴缩放、月度支出、费用构成
- **电池健康**：根据每次充电反推当前容量与 SOH、年均衰减
- **多车辆**：多台车独立记账
- **费用**：分类统计、月度预算、一键导出本月报告
- **导入导出**：小熊油耗 CSV 老数据直接迁移
- **备份**：每日本地快照 + 可推送 NAS，断网也能用

打开即用（PWA，可添加主屏幕）：`https://mx10085.github.io/dian-hao-ji-zhang/`

## 适用场景

- 电摩 / 电动自行车日常能耗账本
- 双电池轮换自动识别
- 电池衰减监测（SOH 曲线，提前发现异常）
- 家庭充电费用统计与预算
- 其他用电设备：只要有功率/电量实体，思路完全通用
